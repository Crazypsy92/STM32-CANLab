# CAN Hardware Wiring

## MCU pin mapping

This project uses CAN1 partial remap 2 on STM32F103C8T6:

| MCU pin | CAN signal | Connection |
| --- | --- | --- |
| PB9 | CAN1_TX | Transceiver TXD |
| PB8 | CAN1_RX | Transceiver RXD |
| GND | Reference | Common ground with the transceiver and other nodes |

PB8/PB9 are selected to avoid the default PA11/PA12 mapping, which overlaps the USB data pins on common STM32F103C8T6 boards.

The firmware configures the CAN remap in `BSP/Src/bsp_can.c`. Because SWJ_CFG is write-only on STM32F1, the remap operation explicitly reapplies JTAG-disabled / SWD-enabled configuration.

## Physical bus topology

```
STM32F103C8T6                 CAN transceiver A
PB9 / CAN_TX  --------------> TXD
PB8 / CAN_RX  <-------------- RXD
                               CANH -----------+---------------- CANH
                               CANL -----------+---------------- CANL
GND -------------------------- GND              |                 |
                                                |                 |
                                      120 ohm at one end   120 ohm at other end
                                                |                 |
                                      Second CAN node / USB-CAN
```

- Use a CAN transceiver with logic levels compatible with the STM32 3.3 V GPIO.
- Connect CANH to CANH and CANL to CANL.
- Use a twisted pair for CANH/CANL.
- Add 120 ohm termination only at the two physical ends of the bus, not at every node.
- Share ground between non-isolated nodes.
- Never connect PB8/PB9 directly to CANH/CANL.

## Internal loopback versus normal mode

The default `BSP_CAN_MODE_SILENT_LOOPBACK` mode routes transmitted frames back to the controller receive path internally while keeping the physical CAN_TX output recessive. It is useful for checking the MCU firmware without a transceiver or second node, but it does not validate the physical bus.

For physical communication, set:

```c
#define BSP_CAN_DEFAULT_MODE BSP_CAN_MODE_NORMAL
```

Use at least one other active CAN node configured for the same nominal bitrate (default 500 kbit/s). CAN acknowledgements are generated by another node that correctly receives the frame; a lone normal-mode transmitter will report an ACK error.

## Default bit timing

With HSE=8 MHz, SYSCLK=72 MHz and APB1 divided by 2:

- PCLK1 = 36 MHz
- Prescaler = 4
- BS1 = 13 TQ
- BS2 = 4 TQ
- SJW = 1 TQ
- Nominal bitrate = 500 kbit/s
- Sample point = 77.8%

If the system clock changes, update `BSP_CAN_PCLK1_HZ` and the timing tuple together.
